# Contributing

Thanks for your interest in improving Sarnia: The Bluewater File.

- **Bug reports:** open a GitHub Issue using the bug report template. Include OS version, hardware, steps to reproduce, expected/actual result, and (when useful) a short log excerpt.
- **Feature requests:** describe the player problem, proposed behaviour, and how it fits the fictional Ontario setting.
- **Code changes:** use Godot 4.4.1, make focused pull requests, document gameplay changes and run relevant tests from `docs/BUILDING.md` if possible.
- **Assets and map work:** respect the game's MIT-licensed original art and the separate ODbL 1.0 obligations for map-derived data/tiles. Preserve third-party notices.
- **Privacy:** do not attach personal data from local saves or machine paths without checking it first.

Please avoid adding unlicensed assets or copying copyrighted game content from other RPGs. Existing game licence terms are in `LICENSE`, `DATA-LICENSE.md`, and `licenses/`.
